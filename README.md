# 방송시간표 메이커

스트리머를 위한 **주간 방송 시간표 이미지 제작 프로그램**입니다. 일정을 입력하면 디자인된 시간표를 PNG / JPEG 이미지로 바로 내보낼 수 있습니다. (Windows 전용)

## 주요 기능

- **템플릿 15종** (일러스트 장식·입체 타이틀·광택 패널 적용, 모든 장식은 직접 제작한 벡터/CSS라서 색상 변경이 자유롭습니다)

  | # | 이름 | 형태 | 사진 |
  |---|------|------|------|
  | 1 | 고정형 | 보라 정사각형 1080×1080 | 없음 (글자만 수정) |
  | 2 | 사진 배경형 | 하늘색 16:9 | 배경 전체에 자유 배치 |
  | 3 | 큐티 핑크 | 핑크 · 체크 배경 | 왼쪽 프레임 |
  | 4 | 스카이 클라우드 | 하늘색 · 구름 | 오른쪽 프레임 |
  | 5 | 라벤더 폴라로이드 | 연보라 · 기울어진 폴라로이드 | 폴라로이드 안 |
  | 6 | 하트 프레임 | 보라 · 하트 모양 | 하트 모양으로 잘림 |
  | 7 | 노트 다이어리 | 크림 · 마스킹 테이프 | 왼쪽 프레임 |
  | 8 | 우드 클립보드 | 나무 · 날짜 탭 · OFFLINE 표시 | 클립보드 안 |
  | 9 | 나이트 카드 | 어두운 보라 · 카드형 · 휴방 카드 | 폴라로이드 |
  | 10 | 스탬프 티켓 | 여행 · 우표 · 티켓 태그 | 우표 안 |
| 11 | 블루 심플 카드 | 하늘색 작은 표 · 구름 · 하트 · 휴방 아이콘 | 없음 |
| 12 | 사이버 HUD | 네온 · 레이더 · 대각선 바 · 요일별 아이콘(게임/채팅/노래) · 스캔라인 | 오른쪽 HUD 프레임 |
| 14 | 라벤더 모눈 노트 | 4:3 · 보라 모눈종이 카드 · 테이프 · 우측 시간표 패널(제목·설명·시간) | 왼쪽 카드 안 |
| 15 | 모노 체커 폴라로이드 | 4:3 · 흑백 체커 · 기울어진 폴라로이드 · 검정 테두리 알약 줄 | 폴라로이드 안 |
| 13 | 내 배경 자유형 | **내가 고른 이미지를 배경으로** 깔고 그 위에 시간표 표시 (스타일 4종: 유리/어둡게/글자만/스티커, 배치 2종: 세로 목록/가로 카드) | 배경 전체 |

  **13번 내 배경 자유형**: `사진` 탭에서 배경 이미지를 넣고 끌어서 위치·크기를 맞춘 뒤, `색상` 탭의 `시간표 배치`에서 표 스타일(유리/어둡게/글자만/스티커), 배치 방식(세로 목록/가로 카드), 위치, 투명도, 크기, 배경 어둡게 정도를 조절합니다.
  **11번 블루 심플 카드**: 요일마다 표시할 내용(예: `AM 2:00`)만 입력하며, `휴방`을 누르면 '휴방'으로 표시됩니다.

  시간 칸에 `OFF`(또는 `OFFLINE`, `휴방`)를 입력하면 템플릿 8~10에서 휴방 디자인으로 자동 전환됩니다.
  사진은 템플릿의 프레임 모양 안에서 드래그로 이동, 모서리 점으로 크기 조절합니다.
- **색상 커스터마이징** — 배경색, 패널색, 포인트색, 글자색, 토요일/일요일 글자색
- **내보내기** — PNG / JPEG, 해상도 1x / 2x / 3x 선택. 미리보기와 결과물이 동일합니다.
- **자동 저장** — 입력한 내용은 자동으로 저장되며, `프로젝트 저장` / `불러오기`로 파일 백업도 가능합니다.
- **오프라인 사용** — 한글 폰트와 모든 리소스가 프로그램에 포함되어 인터넷 없이 동작합니다.
- **자동 업데이트** — 인터넷이 연결되어 있을 때만 새 버전을 확인하고, "업데이트 하시겠어요?" 안내가 뜹니다. 인터넷이 없으면 확인 없이 바로 실행됩니다.

## 다운로드

[Releases](https://github.com/llipp9983/broadcast-schedule-maker/releases) 페이지에서 원하는 버전을 받으세요.

| 파일 | 설명 |
|------|------|
| `BroadcastScheduleMaker-Setup-x.x.x.exe` | **설치 버전** — 설치 후 시작 메뉴/바탕화면에서 실행, 새 버전이 나오면 자동 업데이트 안내 |
| `BroadcastScheduleMaker-Portable-x.x.x.exe` | **포터블 버전** — 설치 없이 더블클릭으로 바로 실행. USB에 넣어 다녀도 됩니다 |

### 포터블 버전 안내
- 입력 내용과 설정은 실행 파일 옆의 `방송시간표-데이터` 폴더에 저장됩니다. 파일을 옮길 때 이 폴더도 함께 옮기면 작업 내용이 유지됩니다.
- 새 버전이 나오면 안내 창이 뜨고, 다운로드 페이지에서 새 포터블 파일을 받아 교체하면 됩니다. (자동 교체는 설치 버전만 지원)
- 처음 실행 시 파일 압축을 푸는 데 몇 초 걸릴 수 있습니다.

### Windows 경고 안내
코드 서명 인증서(유료)를 사용하지 않아 첫 실행 시 "Windows의 PC 보호" 경고가 나타날 수 있습니다. **추가 정보 → 실행**을 눌러 진행하세요.

## 사용 방법

1. 왼쪽 **템플릿 목록**에서 마음에 드는 디자인을 클릭합니다. (작은 미리보기로 바로 확인)
2. 오른쪽 **내용** 탭에서 입력합니다.
   - `이번 주 날짜`: 날짜를 고르거나 `이번 주` / `다음 주`를 누르면 기간과 요일별 날짜가 자동으로 채워집니다.
   - 요일마다 내용과 시간을 입력하고, 쉬는 날은 **휴방** 버튼을 누릅니다.
   - `모든 요일 시간`에서 시간을 한 번에 맞출 수 있습니다.
3. **색상** 탭에서 테마 색상을 한 번에 바꾸거나, 세부 색상을 직접 고릅니다.
4. 사진이 들어가는 템플릿은 미리보기의 **사진 칸을 클릭**하거나 이미지를 **끌어다 놓으면** 추가됩니다. 사진 탭에서 크기 슬라이더, 칸에 맞추기, **회전(90도 버튼·각도 슬라이더), 좌우/상하 반전**, 삭제를 쓸 수 있고, 미리보기에서 직접 끌어 옮길 수도 있습니다.
5. 위쪽에서 형식(PNG/JPG)과 해상도(1x/2x/3x)를 고르고 **이미지로 저장**을 누릅니다. **복사**를 누르면 클립보드에 복사되어 바로 붙여넣을 수 있습니다.

### 단축키

| 키 | 동작 |
|----|------|
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시 실행 |
| Ctrl+E | 이미지로 저장 |
| Ctrl+S | 프로젝트 파일로 저장 |

입력 내용은 자동 저장되며, 다음에 열면 이어서 작업할 수 있습니다.

## 개발자용

필요: Node.js 20 이상

```bash
npm install
npm run start     # 빌드 후 앱 실행
npm run dist      # 설치 파일 + 포터블 파일 생성 (release/ 폴더)
```

기술 스택: Electron, React, Vite, html-to-image, electron-updater, electron-builder

### 새 버전 배포하기

1. `package.json`의 `version`을 올립니다. (예: `1.0.1`)
2. `npm run dist`로 설치 파일을 만듭니다.
3. `release/` 폴더의 `BroadcastScheduleMaker-Setup-x.x.x.exe`, `.exe.blockmap`, `latest.yml`, `BroadcastScheduleMaker-Portable-x.x.x.exe` 네 파일을 GitHub Release(태그 `v1.0.1`)에 업로드합니다.

```bash
gh release create v1.0.1 release/BroadcastScheduleMaker-Setup-1.0.1.exe release/BroadcastScheduleMaker-Setup-1.0.1.exe.blockmap release/latest.yml release/BroadcastScheduleMaker-Portable-1.0.1.exe --title "v1.0.1"
```

설치된 프로그램은 실행 시 `latest.yml`을 확인해 새 버전을 안내합니다.
